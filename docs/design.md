# 松间五子棋 · 产品与技术设计

需求来源：项目说明文档.txt；用户补充：Android 和 iOS 均支持。

实现 Flutter 原生移动应用，使用 universal_ble 的 central/peripheral 模式进行跨平台 BLE 通信，无服务器、无网络依赖。只承诺前台对局；挂起、断连或消息超时后冻结棋盘并提示重新建房，不擅自判负。

大厅打开后申请蓝牙权限，自动广播可加入状态并扫描本游戏服务。用户也可点击创建房间进入等待页；附近玩家点击加入后，双方交换资料并开始对局。不支持 peripheral 模式的设备仅搜索和加入。房主执黑，访客执白，15×15 自由规则，至少五子连线获胜，无禁手，满盘无胜者为和棋。

房主是权威状态源，访客发送带局号和步号的落子请求；房主验证角色、边界、空位、回合、局号和步号后广播快照。访客验证快照后显示。所有消息包含协议版本；以不超过 20 字节的分片发送，长度和序号校验，限制报文大小；串行发送，心跳和快照确认用于发现丢包。网络异常停止对局，不在双方状态不确定时继续落子。

资料包含默认昵称、内置头像或相册缩略图。头像压缩到小尺寸并限制字节数，保存于本地；双方通过 BLE 交换资料。资料只能在大厅编辑。

界面：米白背景、松绿色按钮、暖木纹棋盘、带高光阴影的黑白棋子，胜利连线，清楚区分搜索、等待、连接、自己的回合、对手回合、结束和异常状态。提供同机练习作为额外的离线体验和界面验证入口。

验证：纯 Dart 规则/报文测试，控制器双端模拟传输测试，Flutter widget 测试、静态分析、Android 构建（环境允许时）；Android↔Android、iOS↔iOS、Android↔iOS 双角色真机矩阵必须另行执行，不以模拟测试替代。
